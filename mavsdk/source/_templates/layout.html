This documents mavsdk-grpc

You are reading the reference for the gRPC-based Python wrapper, which was previously published on PyPI as mavsdk and is now published as mavsdk-grpc, imported as mavsdk_grpc. Development continues here, including releases tracking MAVSDK v4.
The mavsdk package now refers to the native MAVSDK binding, which has a different API and no gRPC dependency. See the migration guide.
